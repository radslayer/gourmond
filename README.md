# Gourmond

A playground for experimenting with an AI marketing agent for food businesses.

## What is here

- `index.html` is the home page. It shows `gourmond.jpg` and a one-line tagline. No build step.
- `gourmond.jpg` is the Gourmond illustration.
- `CNAME` holds the custom domain (gourmond.com). GitHub created it; do not delete it.
- `.nojekyll` tells GitHub Pages to serve the files as they are.

## Hosting

The site is served by GitHub Pages from the `main` branch, root folder.
Address: https://gourmond.com

To change the site, edit `index.html` and commit to `main`. GitHub republishes within a few minutes.

## Note

This repository is public. Do not commit customer data, passwords, API keys, or anything proprietary.
